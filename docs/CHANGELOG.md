# 更新日志

## v1.0.0（2026-11-03）

### 切换到 Tauri 2

Murge 从 Electron 整体迁移到 Tauri 2，后台改用 Rust 原生实现。

- **更轻、更快**：不再自带一整套 Chromium，改用 Windows 自带的 WebView2，安装包更小，启动更快。
- **更安全**：更新包必须通过发布签名校验才会安装；安装器改为按机器安装，TUN 服务只信任经过校验的 Murge 程序。
- **和系统结合更紧**：自定义标题栏、磨砂半透明窗口、原生托盘弹窗；关机或注销时先恢复系统代理再退出，关闭窗口最小化到托盘。
- **升级无感**：Electron 版会自动升级过来，配置和数据全部保留。

### 新增

- **HTTPS 解密与重写（侧栏「HTTP」分组）**
  - 解密：一键生成本机专属根证书并安装到系统，只解密「MitM 主机名」列表里的域名（支持通配符、排除、指定端口），每个主机名可单独停用；可选「跳过服务端证书验证」「自动屏蔽 QUIC」「MitM over HTTP/2」。
  - 重写 & 映射：URL 重定向、Header 重写、Mock（Map Local）、Body 重写（正则和 jq）、脚本、分流规则；「N 条规则生效中」可查看具体规则及来源。
  - 模块：通过链接添加 Surge 模块、Loon 插件、Stash / Egern 覆写或 Quantumult X 重写，支持模块参数（#!arguments），可查看模块内容、编辑参数；模块里的 MitM 主机名自动加入解密列表。
  - 脚本：内置 JavaScript 引擎，兼容 Surge / Loon / Quantumult X 的 http-request、http-response 脚本（$httpClient、$persistentStore、$notification 等），BoxJs、Script Hub 可用。
  - 连接页标注「已解密」的连接；「最近解密的请求」可查看每个请求执行了哪些重写和脚本日志。
  - 外部资源新增「模块」「脚本」分类，可单独更新；托盘新增「模块」栏，可逐个开关模块，内核运行中直接生效。
- **本地节点、本地规则与本地策略组**：保存在订阅之外，更新或切换订阅都不会丢失。
  - 「增加代理」窗口按协议切换字段，支持 HTTP(S)、SOCKS5(-TLS)、SSH、Snell、Shadowsocks、VMess、VLESS（含 REALITY）、Trojan、AnyTLS、TUIC v5、Hysteria 2、WireGuard、Tailscale 和绑定网络接口，可设置跳板代理、网络接口、IP 版本、TFO / MPTCP / 多路复用，并加入现有策略组。
  - 「文本」方式可直接粘贴 mihomo YAML、分享链接（ss / vmess / vless / trojan / hysteria2 / tuic / anytls 等）、Surge 代理行或 WireGuard 配置，一次添加多个节点；也可导入 WireGuard .conf 文件。
  - 本地节点以卡片显示，点击编辑；右键可查看延迟和流量、创建副本、停用、删除、测试延迟。
  - 新建策略组向导（类型、策略、名称与选项三步），支持外部策略、包含所有代理、包含其他策略组、过滤正则。
  - 本地规则排在订阅规则之前，可排序、停用；订阅自带的规则也可以停用、改用其他策略或整条替换，修改按订阅分别保存。
- **WireGuard 与 Tailscale**：Tailscale 节点自动添加 *.ts.net 和 tailnet 网段规则并解析 MagicDNS；检测到官方 Tailscale 客户端时，增强模式会把 tailnet 流量交还给它，两者可同时使用。右键节点可查看连接、设备 / 地址、活动和路由详情，相关连接和进程显示对应图标。
- **局域网设备接管与网关模式**：概览页的 HTTP / SOCKS5 代理开关直接切换「允许局域网连接」并显示局域网监听地址；「网关模式」开关会自动开启 IPv4 转发并添加仅限本地子网的防火墙入站规则，关闭或停止内核后自动撤销，不再需要手动运行 PowerShell。设备页区分本机与其他局域网设备，并标注接入方式。
- **签名更新与 Beta 通道**：发现新版本时弹出更新窗口，显示更新内容和下载进度，可一键「重启并安装」；安装包下载后先验证发布签名，签名不符直接丢弃。「关于」页新增「包括 Beta 版本」开关。
- **磨砂半透明窗口**：Windows 11 22H2 及以上使用 Acrylic，21H2 使用 Mica，Windows 10 保持不透明；弹出菜单、对话框、抽屉同样半透明。托盘菜单改为磨砂弹窗，出站模式分段切换，系统代理、TUN 直接用开关。可在「外观」里关闭，高对比度下始终不透明。
- **日志与诊断**：日志页新增「应用」日志来源（解密、脚本、增强模式、网关模式等），可打开日志文件夹、一键导出日志包；导出内容会脱敏 WireGuard / Tailscale 密钥。
- **侧边栏布局**：在「外观」里可以在分组内拖动排序、显示或隐藏侧栏页面，隐藏的页面在「更多」里保留入口，可一键恢复默认。
- 通用设置新增「静默启动」：开启时登录 Windows 后只在托盘运行。
- 外部资源的「数据库来源」新增「立即更新」，重新下载 GeoIP / GeoSite / MMDB / ASN 数据库。

### 优化

- **界面整体重做**：内容区改为圆角面板，页面留白和标题位置统一；概览卡片更紧凑，所有开关统一为蓝色；进程 / 设备详情、活跃连接卡片和外部资源表格重新设计；详情抽屉保持悬浮卡片样式；不常用操作收进「…」菜单；全局隐藏滚动条。
- **活动页**：显示真实网络类型（以太网 / Wi-Fi 名称 / 蜂窝），可直接切换配置；外部 IP 默认隐藏中间部分，点击显示；「总计」改为启动以来累计（含已关闭的连接和上传）；出站模式菜单从文字下方弹出。
- **订阅更可靠**：内核运行时通过当前节点拉取订阅，失败再直连，直连不通或 DNS 被污染也能导入；导入前先用 mihomo 校验配置；远程规则集通过配置里的代理组下载；切换到尚未下载 provider 的配置时会等内核应用完成，不再超时重启。
- **系统代理**：被其他程序（代理客户端、VPN、加速器）改过之后，打开开关即可重新接管，关闭时交还给原来的程序；启动时自动清理残留记录。
- **运行稳定性**：内核崩溃后 10 分钟内最多自动重启 3 次；退出被取消时自动恢复内核；断网后 TUN 状态正确复位。
- **退出更可靠**：退出卡住时最迟约 25 秒自动退出，系统代理未能恢复时提示并提供「强制退出」。
- **更新安装**：不再弹出 PowerShell 窗口，改为显示安装进度窗口，装完自动打开 Murge；某个更新镜像返回错误版本或损坏的安装包时自动换用其他来源。
- 刷新动效重新设计（光弧、成功对勾、失败提示）；「全部更新」显示进度和结果。
- 备份恢复按顺序重启内核，恢复失败回滚时会弹出提示；运行错误和启动崩溃都会写入日志。
- 首页 INTERNET 延迟首次超时自动重试一次；规则页表格随窗口变宽；内核版本选择弹窗更紧凑。
- 「关于」页链接改用系统浏览器打开；界面启用内容安全策略。

### 修复

- 修复连接、进程、活动页里进程图标全部显示成同一个占位图标的问题。
- 修复 Sub-Store 一直提示「启动超时」：首次打开时会自动下载并校验官方 Node.js 运行环境。同时修复「在浏览器中打开」后无法连接后端、按钮错位的问题。
- 修复首页上传 / 下载速率一直为 0、内核日志不刷新，以及修改控制器端口或密钥后流量、连接和日志停止更新的问题。
- 修复策略组里直接放节点时测速全部「失败」（多个订阅有同名节点时会测到别的订阅）的问题。
- 修复部分订阅加载就崩溃（`no entry found for key`）的问题；配置 YAML 的锚点合并、yes/no 写法、BOM、类型标签与 mihomo 理解一致。
- 修复开着 TUN 停止内核后再启动，TUN 显示开启但不生效的问题。
- 修复切换内核版本或通道后仍在运行旧内核，以及托盘「重启内核」「重载配置」无效的问题。
- 修复开机自启开关无效、提示「系统未确认开机启动设置」的问题。
- 修复系统代理开启时修改绕过规则，30 秒后被还原并误判为外部修改的问题。
- 修复手动选过日间或夜间后，切回「跟随系统」仍停留在之前主题的问题。
- 修复内核启动失败时托盘「退出」没有反应的问题。
- 修复日志「导出」「导出诊断」点击无反应的问题，现在弹出保存对话框。
- 修复规则页长规则把表格撑开、右侧使用次数和来源列被截断的问题。
- 修复冷启动后「网络延迟」首次测速没有结果的问题。
- 修复卸载后残留系统级卸载记录的问题。

### 变更

- Electron 版已停止更新（最后一个版本为 v0.9.38），会自动升级到本版本。
- 「关于」页的「稳定版 / 实验版」切换改为「包括 Beta 版本」开关，默认只接收正式版。
- 「设备」和「Sub-Store」默认不在侧栏，可从「更多」进入，或在「外观 › 侧边栏布局」里放回侧栏。
- HTTPS 解密只在规则模式下生效；银行等启用证书锁定的应用请不要加入解密列表。
