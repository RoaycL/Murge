# 本地配置备份与恢复

在「通用 → 配置备份与恢复」设置至少 8 位密码，然后选择本地文件保存。备份使用 scrypt 派生密钥与 AES-256-GCM 加密；Murge 不保存密码，也不自动上传。请妥善保管备份文件和密码，密码丢失无法恢复。

备份包含应用网络设置、覆写、配置文件、订阅地址和 Sub-Store 用户数据。订阅地址会先由本机安全存储解密，再放入**加密**备份；恢复到另一台电脑时会用该电脑的安全存储重新加密。日志、缓存、内核程序和系统服务不在备份范围内；外观偏好保存在 Electron 本地存储中，也不在本版备份范围内。

恢复前须输入密码并选择备份。预览会显示来源版本、配置数量以及将替换、新增、移除的文件数量。格式不受支持、来源主版本不同、0.x 版本的次版本不同，或备份来自比当前安装版更新的 Murge 时，确认按钮不可用。确认后 Murge 安排重启，在下一次启动读取设置前应用备份；如果文件写入失败，会恢复原配置并提示。恢复不会改变 Windows 开机任务、核心服务或系统代理的系统级注册状态。需要重新联网时，应检查内核、TUN 和系统代理的实际状态。

此阶段仅实现本地备份；WebDAV 可在本地恢复流程经使用验证后再接入。
