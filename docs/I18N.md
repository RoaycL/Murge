# 多语言 / Localization

界面文案放在语言文件里，源语言是简体中文（`zh-CN`），目前另有英文（`en`）。

| 位置 | 内容 |
| --- | --- |
| `src/shared/i18n/locales/<locale>.json` | 主窗口的全部文案 |
| `src-tauri/locales/<locale>.json` | 托盘菜单、托盘提示和系统通知 |

键是扁平的 `命名空间.名称`（如 `about.title`），参数写成 `{0}`、`{1}`。

## 在代码里使用

```ts
import { t } from '@shared/i18n'

t('common.save')                    // 保存 / Save
t('profiles.lineError', [3, text])  // 第 3 行：… / Line 3: …
```

```rust
use crate::i18n::{t, tf};

t("tray.show");
tf("tray.quit", &[product]);
```

新增文案时在 `zh-CN.json` 和 `en.json` 里各加一条。模块顶层的常量只求值一次，
请写成 getter 或函数（参考 `src/renderer/src/lib/sidebar-layout.ts`），否则切换语言后不会更新。

## 新增一种语言

1. 复制 `zh-CN.json` 为 `<locale>.json`（两个目录各一份）并翻译。
2. 在 `src/shared/i18n/index.ts` 的 `Locale`、`LOCALES`、`LOCALE_NAMES`、`MESSAGES`、`matchLocale` 里登记；
   在 `src-tauri/src/i18n.rs` 的 `Locale`、`messages`、`match_locale`、`resolve` 里登记；
   `src-tauri/src/settings.rs` 的 `is_valid_language` 也要接受它。
3. `npm test`：`tests/i18n.test.ts` 会检查各语言的键和参数是否与 `zh-CN` 一致、源码里是否还有写死的文案、
   每个键是否都有用到。

语言设置在「更多 › 通用 › 语言」：跟随系统、简体中文、English，切换后立即生效。
内核与后端服务返回的错误详情目前仍是中文。
