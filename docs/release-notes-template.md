# Murge {{VERSION}}

## Murge 正式版

- 从这个版本开始，新的 Tauri 版就是 Murge 正式版，以后只更新这一个版本。原来 Electron 稳定版的用户会自动升级过来，配置和数据全部保留。
- 关于页的「稳定版 / 实验版」切换改成了「包括 Beta 版本」开关。默认只收到正式版；打开后也会收到更早发布的 Beta 版本。

## 本次更新

- 进程、设备详情页和活动页的活跃连接卡片重新设计；外部资源改为一张表格显示；侧边栏「配置」图标换成更简洁的样式。
- 远程规则集改为通过配置里的代理组下载。
- 活动页顶部对照 Surge 调整：标题留出间距，网络、配置、出站模式、外部 IP 和下方卡片对齐；外部 IP 和出站模式加了下拉箭头，出站模式菜单从文字下方弹出，打开时文字不再跳动。
- 修复连接、进程、活动页面里进程图标全部显示成同一个占位图标的问题。
- 修复 Sub-Store 一直提示「启动超时」的问题：第一次打开时会自动下载并校验官方 Node.js 运行环境（约 36MB），之后直接使用缓存。启动失败会立即显示原因。
- 修复首页上传、下载速率一直为 0，以及内核日志不再刷新的问题。
- 首页 INTERNET 延迟在代理测速第一次超时时会自动重试一次，减少点刷新后显示「—」的情况。
- 连接页搜索框、排序框和「关闭全部」按钮的圆角统一。
