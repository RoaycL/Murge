## 本次更新

- 修复策略组里直接放节点时测速全部显示「失败」的问题。多个订阅里有同名节点（例如都叫 `hysteria2`）时，测速会测到别的订阅里的同名节点；现在只测这个策略组实际使用的订阅里的节点。
- 导入或更新订阅时会先用 mihomo 校验配置，有问题的配置会直接提示，不会导入后才启动失败。
- TUN 服务没装好或暂时不可用时也能正常导入订阅，校验会改用本地 mihomo 完成。
- 修复开着 TUN 停止内核后，再启动时 TUN 显示已开启但实际不生效的问题。
- 修复在「内核版本」里切换版本或通道后，实际仍在运行旧内核的问题；托盘「重启内核」现在会真正重启。
- 修复正式版托盘「重载配置」没有效果的问题。
- 修复修改控制器端口或密钥后，首页流量、连接列表和日志不再更新的问题。
- 从体验版切回稳定版点「重启并安装」时，不再弹出 PowerShell 窗口。
