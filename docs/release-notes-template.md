# Murge {{VERSION}}

## 新增

- **节点缺少策略组提示**：本地节点要加入的策略组在当前配置里不存在时，节点卡片显示「缺 N 个策略组」（悬停可看到组名），编辑器里也会说明；设置会保留，切换到有这些组的配置后自动加入。

## 优化

- **保存前先校验配置**：本地节点、规则、策略组和 HTTPS 解密 / 重写的改动，生效前先用内核完整校验最终配置；内核不接受时恢复原设置并显示内核给出的错误，不再把坏配置推给内核。
- **热重载失败有提示**：校验通过但热重载失败时会写入日志，本地编辑还会在界面上提示，不再悄悄失败。
- **WebDAV 备份表单重做**：地址、用户名、密码、文件路径、加密口令分开填写，自动拼出完整备份地址（默认 Murge/murge.murge-backup）并实时显示；WebDAV 使用独立的加密口令，不再依赖本地备份密码；密码和口令可显示 / 隐藏。本地两栏改名为「保存到本地文件」「从本地文件恢复」。

## 修复

- 修复只建了本地策略组、没有本地节点和规则时，策略组不会加入配置的问题。
- 修复 WebDAV 上传到不存在的文件夹时失败（409）的问题，现在会自动逐级创建文件夹后重试。
