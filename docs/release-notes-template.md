# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 修复升级时提示“TUN 服务安装失败”的竞态：Windows 将旧服务报告为已停止后，服务映像文件仍可能被短暂占用，现在会等待文件释放后再完成替换。
- 服务程序替换加入有界重试；升级不会再因瞬时 `Access is denied` 把服务遗留在停止状态，系统代理和 TUN 均可在更新后正常恢复。
- 新增真实 Windows 文件占用回归测试，覆盖旧服务 EXE 尚未释放时的升级路径。
- 安装器会在核心服务首次安装失败后自动等待并重试；若仍失败，会明确提示系统代理与 TUN 都不可用，避免误导用户继续使用损坏的升级状态。
- 修复保留旧服务的升级路径遗漏 Windows 服务类型、导致 UpdateConfig 返回“参数错误”的问题；同时按兼容性要求回退父目录 ACL 扩大加固，仅保留服务程序与状态目录保护。安装失败时会显示具体阶段，不再只有通用错误码 2。
- Windows TUN 网卡名统一为 Mihomo，与 Clash Party、Clash Verge Rev 保持一致；启用前识别仍被其他客户端占用的 Mihomo TUN，保留当前内核和系统代理并明确报告冲突，不再让内核反复退出造成断网。
