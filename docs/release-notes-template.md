# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 内核在重启后反复崩溃时，自动重启次数限制为每 10 分钟 3 次，超过后只还原系统代理和虚拟网卡，不再无限重启。
- 特权服务停止或连续崩溃后，界面不再误显示"运行中"，并会自动还原系统代理，避免代理指向已失效的端口。
- 内核启动持续失败时不再无限重试；退出应用过程中网络重连也不会再次打开系统代理。
- 关闭"自动检查更新"后，应用不再在后台检查和静默安装更新。
- 活动页和策略页会显示内核当前的出站模式，托盘切换模式后界面同步更新。
- 订阅大小上限从 2 MiB 提高到 16 MiB，配置备份的单文件上限同步提高，大订阅可以正常备份和还原。
- 安全加固：禁止通过 Murge 程序运行任意 Node 脚本或调试，并校验程序资源完整性。
