# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 启动性能优化：主窗口不再等待恢复流程完成——存储与应用设置在进程启动时即预热，系统代理恢复、特权服务与 TUN 状态的恢复延后并行执行，界面更早可用。
- 开机自启升级为 Windows 计划任务：登录后延迟数秒再启动，避开登录时的磁盘与 CPU 争用高峰，并以更高的进程优先级运行；全程无需管理员权限，不弹 UAC。企业策略禁用计划任务时自动回退到原有注册方式。切换「静默启动」、升级安装与卸载时的注册状态会被自动校正与清理，不再出现参数不同步或残留失效启动项。
- 外部资源内容预览：节点与规则的外部资源（proxy-providers / rule-providers）可在资源页直接查看——文本与 YAML 资源显示原文，MRS 二进制资源转换为可读规则（单资源上限 4 MiB）。
