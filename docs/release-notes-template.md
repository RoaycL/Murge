## 本次更新

- 新增或更新远程订阅时，内核在运行的情况下会先通过当前配置的节点去拉取，失败再直连。直连连不上订阅地址、或本地 DNS 被污染时，也能正常导入和更新。
- 切换到 proxy-providers / rule-providers 还没下载过的配置时，不会再因为等待超时而重启内核；会等 mihomo 应用完新配置，再恢复之前选择的节点。
- 内核崩溃后的自动重启次数和稳定版一致（10 分钟内最多 3 次）。
- 退出过程中内核意外退出、而退出又被取消时，会自动恢复内核，不用再手动启动。
- 断网时如果 TUN 处于启动中或失败状态，联网后 TUN 状态会正确复位。
