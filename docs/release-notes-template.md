# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 「连接」详情可从目标域名创建精确或子域名分流规则，保存前预览并可撤销本次添加。
- 新增连接路径诊断：查看命中规则与策略链，并探测当前 DNS、网关、DIRECT 出站、代理及 TUN 状态。探测结果仅供排查参考，不代表既有连接的实时出口。
- 「使用历史」新增按应用统计的流量排行；仅在本机保存进程名，统计依据连接快照，可能低于总流量。
- 配置备份支持手动上传至 HTTPS WebDAV，以及下载后预览和恢复；备份仍使用密码加密，WebDAV 凭据不保存。
- 「进程」列表在可识别程序路径时显示应用图标。
