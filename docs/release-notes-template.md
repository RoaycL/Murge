# Murge {{VERSION}}

> 这是 Beta 测试版本，只推送给在「关于」里打开了「包括 Beta 版本」的用户。

## 本次更新

- 新增「本地节点」和「本地规则」，参照 Surge / Loon 的配置分离：保存在订阅之外，更新或切换订阅都不会丢失。
  - 策略页「本地节点」以卡片显示，点击编辑，右键可查看延迟和启动以来的流量、创建副本、停用、删除、测试延迟。
  - 新的「增加代理」窗口按协议切换字段，必填 / 可选分开标注；支持 HTTP(S)、SOCKS5(-TLS)、SSH、Snell、Shadowsocks、VMess、VLESS（含 REALITY）、Trojan、AnyTLS、TUIC v5、Hysteria 2、WireGuard、Tailscale 和绑定网络接口，可设置跳板代理、网络接口、IP 版本、TFO / MPTCP / 多路复用，并加入现有策略组。
  - 「文本」方式可直接粘贴 mihomo YAML、分享链接（ss / vmess / vless / trojan / hysteria2 / tuic / anytls 等）、Surge 代理行或 WireGuard 配置，一次添加多个节点；也可以导入 WireGuard .conf 文件。
  - Tailscale 节点：自动添加 *.ts.net 和 tailnet 网段规则，并通过它解析 MagicDNS；没有出口节点时延迟显示「仅 tailnet」。
  - 检测到官方 Tailscale 客户端时，增强模式会把 tailnet 流量和 MagicDNS 交还给它，两者可以同时使用（可关闭）。
- 规则页：
  - 「本地规则」排在订阅规则之前，可排序、停用；指向不存在策略的规则会被跳过并提示。
  - 订阅自带的规则可以停用、改用其他策略或整条替换，修改按订阅分别保存；订阅里找不到对应规则时标为「已失效」。

## 此前 Beta 已包含

- 侧边栏：「设备」和「Sub-Store」移入「更多」页；「更多」始终固定在底部，窗口较矮时导航区可滚动（不显示滚动条）。
- 「更多」页顺序调整为 通用、外观、网络、DNS 与嗅探、内核、设备、Sub-Store、日志、关于。
- 活动页：
  - 「网络」显示真实网络类型（以太网 / Wi-Fi 名称 / 蜂窝 / 无网络），「配置」可直接切换。
  - 「外部 IP」默认隐藏中间部分，点击 IP 显示完整地址（10 秒后自动隐藏），点击标签打开网络信息抽屉。
  - 「总计」改为从启动以来累计，包含已关闭的连接和上传流量；排行按上传 + 下载统计。
  - 「网络延迟」修复冷启动后首次测速没有结果的问题，刷新按钮与文字对齐。
- 重写 & 映射：
  - 「N 条规则生效中」可点击查看具体生效的规则及来源。
  - 模块新增「查看」按钮，抽屉展示模块内容；带参数的模块新增「编辑参数」抽屉（开关 / 选项 / 文本）。
  - 模块的删除、清除改为按钮样式。
  - 支持 Surge、Loon、Stash、Egern、Quantumult X 五种格式的模块 / 插件（已用 DualSubs 验证）。
- 外部资源：新增「模块」「脚本」分类，可单独更新重写模块和其中引用的脚本；空列表提示居中显示。
- 选择内核版本的弹窗布局更紧凑。
- 新增「解密」和「重写 & 映射」（侧栏 HTTP 分组），界面对齐 Surge：
  - HTTPS 解密：一键生成本机专属根证书并安装到系统，只解密「MitM 主机名」列表里的域名（支持通配符、排除、指定端口），每个主机名可单独勾选停用；可选「跳过服务端证书验证」「自动屏蔽 QUIC」「MitM over HTTP/2」。
  - 重写 & 映射：URL 重定向、Header 重写、Mock（Map Local）、Body 重写（支持正则和 jq）、脚本、分流规则，卡片显示生效规则数（含模块）并可直接编辑。
  - 模块：通过链接添加 Surge 模块、Loon 插件或 Quantumult X 重写，支持模块参数（#!arguments）；模块里的 MITM 主机名自动加入解密列表。
  - 脚本：内置 JavaScript 引擎，兼容 Surge / Loon / Quantumult X 的 http-request、http-response 脚本（$httpClient、$persistentStore、$notification 等），已验证 BoxJs、Script Hub 可用。
  - 连接页标注「已解密」的连接；「最近解密的请求」可查看每个请求执行了哪些重写和脚本日志。
- 解密只在规则模式下生效，银行等启用证书锁定的应用不要加入解密列表。
- 概览页「网关模式」变为真正的开关：打开后由 TUN 服务自动为 TUN 网卡和上网网卡开启 IPv4 转发，并在 Windows 防火墙中添加仅限本地子网的入站规则；关闭或停止内核后自动撤销，不再需要手动运行 PowerShell 或把网络改为专用网络。（需要随本版本一起更新的安装包 / TUN 服务）
- 打开「允许局域网连接」的 HTTP / SOCKS5 代理时，同样会自动放行局域网访问的防火墙规则。
- 通用设置新增「静默启动」开关：开启时登录 Windows 后只在托盘运行，关闭则自动弹出主窗口（默认开启）。
- 外部资源的「数据库来源」新增「立即更新」，让内核按设置的地址重新下载 GeoIP / GeoSite / MMDB / ASN 数据库。
- 各设置页的「当前生效配置」对比移到页面最底部；加密备份两侧的按钮对齐到同一水平线。
- 详情抽屉保持悬浮卡片样式，打开时右上角的最小化 / 最大化 / 关闭按钮移到抽屉右上角，不再和抽屉边角重叠。
- 透光质感对齐 Surge：日间窗口底更白、卡片接近实白；夜间窗口底和叠加层更通透，卡片改为半透明深色。侧边栏收窄到 190px。
- 进程 / 设备列表直接铺在叠加层上，去掉多出来的一层卡片底。
- 全局不再显示滚动条（含 Sub-Store 内嵌页），内容仍可正常滚动。
- 修复网络信息抽屉「刷新 / 显示」和 Sub-Store「订阅更新」按钮错位、上边框缺失的问题。
- 修复 Sub-Store「在浏览器中打开」后提示无法连接后端的问题。
- Sub-Store 内嵌页背景改为透明，直接透出 Murge 的叠加层。
- 修复手动选过日间或夜间后，切回「跟随系统」仍停留在之前主题的问题。
- 磨砂窗口下，内容叠加层和活动 / 概览 / 配置页的卡片更通透；下拉菜单、对话框、详情抽屉等弹出卡片改为半透明加背景模糊（高对比度下仍不透明）。
- 弹出卡片和活动、概览页不再显示滚动条，内容仍可正常滚动。
- 新增「局域网设备接管」：概览页的 HTTP / SOCKS5 代理开关直接切换「允许局域网连接」并显示局域网监听地址，内核运行中切换即时生效；网关模式卡片可跳转到网络页的设置指引。设备页会区分本机与其他局域网设备，并标注代理或网关接入方式。
- 界面改为 Surge 式布局：内容区作为圆角面板浮在侧栏底色上，活动 / 概览 / 配置使用一整块背景；各页面留白与大标题位置统一；概览卡片比例更紧凑；所有开关打开时统一为蓝色。
- 进程 / 设备页的「创建分流规则」「关闭设备连接」等操作移入「…」菜单。
- 修复开机自启显示「系统未确认开机启动设置」、开关无效的问题：现在直接启用或停用安装器注册的计划任务，不可用时退回到用户启动项。
- 修复「关于」页「包括 Beta 版本」开关样式被按钮样式覆盖、切换后不变色的问题。
