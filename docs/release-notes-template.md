# Murge {{VERSION}}

## 本次更新

- 窗口背景改为磨砂半透明：Windows 11 22H2 及以上使用 Acrylic，Windows 11 21H2 使用 Mica，Windows 10 保持原来的不透明背景。可在「外观 > 窗口 > 磨砂半透明背景」里关闭，开启高对比度时始终不透明。
- 修复系统代理被其他程序（其他代理客户端、VPN、加速器）改过之后，开关一直报「系统代理已被外部修改」、再也无法启用的问题。现在手动打开开关就会重新接管，关闭时把代理交还给原来的程序。启动时如果其他程序已经关掉了代理，会自动清理残留记录，不再提示冲突。
- 修复系统代理开启时修改绕过规则，30 秒后被自动还原、再次修改又被误判为外部修改的问题。
- 概览页系统代理卡片的冲突提示改为「已被其他程序接管，打开开关可重新接管」，具体变动的项目放在悬停提示里。
