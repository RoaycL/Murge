# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 新增内核滚动通道：可在内核设置中切换 MetaCubeX 预览版（preview）与 Smart 内核（smart）；每个发布代际按内容摘要独立钉定信任并保留上一代自动回滚，滚动更新不再失败。
- 内核设置新增「持久化选组」与「持久化 fake-ip 映射」开关（对应 mihomo `profile.store-selected` / `store-fake-ip`）。
- 开机自启回退更可靠：计划任务被系统策略拒绝时自动写入可独立校验的注册表回退项，切换或关闭自启时精确清理，不再依赖参数敏感的登录项查找。
- 特权服务安全加固：版本化内核的信任锚外移至受保护目录、服务目录逐级硬化并拒绝重解析点、客户端身份校验引入 NTFS 卷与文件标识——三类本地提权路径被阻断。
- 修复用量历史面板在快速开关抽屉时的定时器泄漏；「活动」页总计卡片改为仅反映当前连接快照，不再用当前比例外推历史构成。
- 内核诊断命令输出增加 10 秒超时与 512 KB 上限，诊断不再可能无限等待或无限增长。
- 应用设置文件损坏时自动隔离保留现场，再以默认值重建，便于排查与恢复。
- 外部资源内容预览错误细分（读取失败与转换超时独立提示），并拒绝符号链接与非 UTF-8 内容。
