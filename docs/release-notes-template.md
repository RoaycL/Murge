# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 配置热重载：编辑、激活或导入订阅后优先保活内核进程原地生效——TUN 网卡、监听器与自有系统代理不再因更换配置而重建，路由与连接保持；仅当原地重载失败时才回退到完整的内核重启。
- 订阅拉取优先经当前代理/TUN 路由：仅在代理环境下无法直连的订阅主机不再等待直连超时；直连保留为回退路径，HTTP 4xx/5xx 仍不重试。
- 更新检查始终以远端最新版为准：即使旧更新已经下载，也可以继续发现并替换为更新版本；多个镜像源切换期间不再提前显示失败。
- Windows 更新通知支持点击后唤醒 Murge 并直接进入「关于」页面，方便立即重启安装；同时消除非 Web Installer 更新的配置警告。
- 修复用量历史并发写入导致的 `EPERM`、未处理异常和临时文件残留；应用退出时会等待历史数据完成落盘。
- 修复下拉菜单在卡片边界内被裁切的问题，菜单会根据窗口可用空间自动选择展开方向并完整显示。
- 优化网络诊断：打开诊断抽屉时同步刷新延迟卡片，精简重复内容，并将出口网络信息移到服务解锁测试之前。
- 外部资源批量更新提速：多个订阅/规则源以受限并发（2 路）并行拉取，慢源不再阻塞后续资源更新。
