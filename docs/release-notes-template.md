# Murge {{VERSION}}

## 优化

- **记住窗口大小**：调整主窗口大小后，下次启动会恢复到上次的大小（含最大化状态）。
- **图标和 WebDAV 备份先直连、再走代理**：策略图标下载和 WebDAV 备份 / 恢复先直接连接，连不上时自动改走当前节点重试。订阅更新仍然先走节点，失败后的直连现在是真正的直连。

## 修复

- 修复开着系统代理时，读取策略、启用 TUN 等对本机内核的请求被送进代理节点，导致「无法读取策略（HTTP 502）」和 TUN「启用失败」的问题。现在这些请求始终直连本机，不受系统代理和分流规则影响。
- 修复解锁检测没有经过节点的问题：未开 TUN 时测到的是本机直连的结果。
