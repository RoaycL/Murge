# Murge {{VERSION}}

基于 mihomo 内核的 Windows 桌面客户端。

## 本次更新

- 特权内核服务改为随 Windows 正常自动启动，不再等待系统的延迟启动窗口；升级安装会同步修正已有服务设置。
- 加快 Windows 登录后的内核恢复：移除计划任务的 3 秒延迟，并让内核、TUN 与系统代理恢复更早开始，不再被无关的界面和后台初始化阻塞。
- 开机自启固定为托盘静默启动，不再弹出主窗口；升级时会自动改写旧的可见启动项和带延迟的计划任务。
- 修复从任务栏托盘菜单选择“退出”后应用仍停留、需要再次打开窗口才退出的问题；退出现在会直接进入有序清理并在完成后结束进程。
- 保留安全退出顺序：先还原系统代理、停止 TUN 和内核，再释放后台服务与日志，避免遗留代理设置或内核进程。
