# Source code access

Murge is licensed under GPL-3.0-only. The Corresponding Source for each released
binary is available from the Git tag matching that binary's version:

https://github.com/RoaycL/Murge

The Windows installer also contains an unmodified official mihomo v1.19.30
archive. Its source is available at:

https://github.com/MetaCubeX/mihomo/tree/v1.19.30

Use the release tag and `SHA256SUMS.txt` shipped beside the installer to identify
the exact Murge source and binary. Build instructions are in the repository.
